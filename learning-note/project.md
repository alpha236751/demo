## 测评
### RAGAS
RAGAS是专门评测RAG系统的框架。它通常利用大模型作为评审，对问题、检索内容、生成答案和参考答案进行分析。

一条评测数据通常包含：

```python
{
    "question": "Amazon商品被下架后如何申诉？",
    "contexts": [
        "商品下架后，可在卖家后台查看违规原因……",
        "申诉时需要提交商品证明和整改材料……"
    ],
    "answer": "可以先查看下架原因，然后准备证明材料并提交申诉。",
    "ground_truth": "登录卖家后台查看违规原因，准备证明材料后进入申诉入口提交。"
}
```

然后计算：

* Context Precision
* Context Recall
* Faithfulness
* Answer Relevancy

需要注意：RAGAS很多指标依赖 LLM Judge，不是完全确定性的传统公式。因此项目中最好固定：

* 评测模型
* Prompt
* 温度参数
* 测试集
* RAGAS版本

否则多次评测结果可能存在小幅波动。

### 完整的评测流程

你可以这样描述项目中的评测过程：

1. 从真实业务问题中抽取100～300条代表性问题。
2. 由业务人员为每个问题整理参考答案和相关知识文档。
3. 运行RAG系统，保存检索上下文与生成答案。
4. 使用RAGAS计算检索和生成指标。
5. 对低分案例进行人工分析。
6. 优化切分、召回、重排序和Query Rewrite。
7. 使用同一测试集重新评测，对比优化前后的指标。

必须使用同一批测试数据，优化前后的指标才有可比性。
